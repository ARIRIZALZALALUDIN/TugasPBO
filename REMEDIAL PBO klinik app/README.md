# Aplikasi Sistem Klinik Sederhana

Aplikasi desktop berbasis Java Swing untuk manajemen data pasien, dokter, obat, dan resep di klinik.

## Kebutuhan Sistem (Prerequisites)
* JDK 8 atau versi lebih baru
* XAMPP (MySQL Server)
* Connector Java MySQL (`mysql-connector-j`)

## Cara Cepat Menjalankan
1. Buka XAMPP, jalankan service **Apache** dan **MySQL**.
2. Buka phpMyAdmin (`http://localhost/phpmyadmin/`).
3. Buat database baru dan import / jalankan skrip SQL dari file `klinik_db.sql`.
4. Jalankan file `Main.java` dari IDE (VS Code / Eclipse / NetBeans).
